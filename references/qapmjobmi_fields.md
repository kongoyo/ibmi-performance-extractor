# QAPMJOBMI 完整欄位對照（官方文件）

> **來源**：IBM 官方 Collection Services 文件 "Collection Services data files: QAPMJOBMI"（Last Updated: 2024-05-07）。此檔在 `CRTPFRDTA` 指定 `*JOBMI` 種類時產出，含每個 job/task/thread 每個 interval 的作業、主要及次要執行緒資料；「資料收集服務」提供的資料僅適用於在間隔期間內使用 CPU 的工作。`QAPMJOBL` 結合本表與 `QAPMJOBOS` 的資料（見 `qapmjobl_fields.md` 開頭說明），因此本表是 `QAPMJOBL` 目前已使用之 CPU/I/O/Seize-Wait/分頁缺失類欄位的原始來源。
>
> **⚠️ 這是官方說明文字，不是實測結論**：跟 `JBPAGF` 曾經誤導過本專案一樣，「欄位存在、說明文字合理」不等於「這個欄位在本環境真的可用、單位/語意跟你以為的一樣」。任何要拿本表欄位寫進 SQL 查詢或改動現有計算邏輯的動作，都必須先照 [field_reference.md](field_reference.md) 開頭規定的流程實測驗證，才能更新 `field_manifest.json` / `field_reference.md`。本表本身只是查找起點。
>
> 已驗證、目前實際用在報表計算的對應 `QAPMJOBL` 欄位見 [field_reference.md](field_reference.md) 第四節；本表與 `qapmjobl_fields.md` 交叉比對的結果（`JBPAGF` 死欄位獨立佐證、`JBSZWT` 語意/型別一致、`JBHSQLSTMT` 與 `QAPMJOBOS.JBSQLSTMT` 命名易混淆須注意）已記錄於對話歷史，尚待後續補進本文件或 `field_reference.md` 變更記錄。
