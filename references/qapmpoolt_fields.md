# QAPMPOOLT 完整欄位對照（官方文件）

> **來源**：IBM 官方 Collection Services 文件 "Collection Services data files: QAPMPOOLT"（Last Updated: 2024-05-07）。此檔包含主要儲存區（Pool）檔案項目，列出儲存區的**調整資訊**（tuning info：調整類型、變更頁處理方式、各類別區塊因數/交換設定），欄位內容與 [qapmpool_qapmpooll_fields.md](qapmpool_qapmpooll_fields.md) 的 `PTxxx` 系列欄位重疊（同一組調整參數，本表是獨立的專屬檔案）。
>
> **⚠️ 這是官方說明文字，不是實測結論**：跟 `JBPAGF` 曾經誤導過本專案一樣，「欄位存在、說明文字合理」不等於「這個欄位在本環境真的可用、單位/語意跟你以為的一樣」。任何要拿本表欄位寫進 SQL 查詢或改動現有計算邏輯的動作，都必須先照 [field_reference.md](field_reference.md) 開頭規定的流程實測驗證，才能更新 `field_manifest.json` / `field_reference.md`。本表本身只是查找起點。
>
> **目前狀態：完全未使用**。與 [qapmpool_qapmpooll_fields.md](qapmpool_qapmpooll_fields.md)、[qapmpoolb_fields.md](qapmpoolb_fields.md) 同屬「Pool 狀態」功能缺口的一部分，尚未有任何查詢、欄位驗證或 `field_reference.md` 記錄。

## 完整欄位清單

> 以下為原始官方文件內容，維持未經改寫的原貌（僅補上方引用/警語區塊，不改動任何欄位資料本身，避免在未逐欄核對格式的情況下引入轉寫錯誤）。

```text
欄位名稱	說明	屬性
INTNUM	間隔號碼：第 n 個取樣資料庫間隔（基於「建立效能資料 (CRTPFRDTA)」指令中所指定的開始時間）。	PD (5,0)
DTETIM	間隔日期 (yymmdd) 與時間 (hhmmss)：取樣間隔的日期與時間（以本端系統時間表示）。	C (12)
INTSEC	經歷的間隔秒數：自前一取樣間隔後的秒數。	PD (7,0)
DTECEN	世紀數字。	C (1)
PONBR	儲存區號碼：指定此儲存區的唯一 ID。 值是從 1 到 64。	C (3)
PTTYPE	調整類型：系統用來調整儲存區的方法：
0 -- 不調整
1 -- 靜態調整
2 -- 動態調整主要儲存體的轉送
3 -- 動態調整主要儲存體及輔助儲存體的轉送。
C (1)
PTPAGE	變更頁處理。 系統用來決定何時將變更頁寫入輔助儲存體的方法：
0 -- 使用系統預設值
1 -- 定期地將變更頁轉送至輔助儲存體。
C (1)
PTNDBF	非資料庫區塊因數。 要求從輔助儲存體中讀取非資料庫物件時，應送至主要儲存體的資料量（以 KB 為單位）。	PD (3,0)
PTDBF1	資料庫區塊因數（類別 1）。 要求從輔助儲存體中讀取資料庫物件時，應送至主要儲存體的資料量（以 KB 為單位）。	PD (3,0)
PTDEX1	資料庫交換作業類型 （類別 1）。 交換作業是用來減少工作組大小。
0 -- 使用系統預設值
1 -- 容許交換作業
2 -- 停用交換作業
3 -- 停用交換作業
在儲存區中需要額外的儲存體時，可以考慮置換已經存在於主要儲存體中的資料。

C (1)
PTDTS1	轉送至輔助儲存體的資料庫類型（類別 1）。 系統用來處理寫入物件至輔助儲存體要求的方法。
0 -- 使用系統預設值
1 -- 從主要儲存體中清除物件
2 -- 將物件寫入輔助儲存體
3 -- 表示物件是不錯的置換候選
4 -- 使用系統頁置換演算法
C (1)
PTDBF2	資料庫區塊因數（類別 2）。 請參閱 PTDBF1。	PD (3,0)
PTDEX2	資料庫容許交換作業（類別 2）。 請參閱 PTDEX1。	C (1)
PTDTS2	轉送至輔助儲存體的資料庫類型（類別 2）。 請參閱 PTDTS1。	C (1)
PTDBF3	資料庫區塊因數（類別 3）。 請參閱 PTDBF1。	PD (3,0)
PTDEX3	資料庫容許交換作業（類別 3）。 請參閱 PTDEX1。	C (1)
PTDTS3	轉送至輔助儲存體的資料庫類型（類別 3）。 請參閱 PTDTS1。	C (1)
PTDBF4	資料庫區塊因數（類別 4）。 請參閱 PTDBF1。	PD (3,0)
PTDEX4	資料庫容許交換作業（類別 4）。 請參閱 PTDEX1。	C (1)
PTDTS4	轉送至輔助儲存體的資料庫類型（類別 4）。 請參閱 PTDTS1。	C (1)
DATETIME	間隔日期與時間：取樣間隔的日期與時間（以本端系統時間表示）。	時間戳記
UTCTIME	UTC 間隔日期與時間：取樣間隔的日期與時間（以世界標準時間 (UTC) 表示）。	時間戳記
```
